# Радар ниш YouTube: инструкция

## 1. Получить API-ключ (бесплатно, 5 минут)
1. Откройте https://console.cloud.google.com/ и создайте проект.
2. «APIs & Services» → «Library» → найдите **YouTube Data API v3** → **Enable**.
3. «APIs & Services» → «Credentials» → **Create credentials → API key**. Скопируйте ключ.

## 2. Запуск
Нужен только Python 3.8+, библиотеки устанавливать не надо.

```
python niche_radar.py --demo                     # проверка без ключа
python niche_radar.py --key ВАШ_КЛЮЧ             # реальный скан
python niche_radar.py --key ВАШ_КЛЮЧ --regions US,PL,DE --days 5 --max-subs 10000
```

Результат появится в папке `radar_output`:
- `report.html` — отчёт с рейтингом ниш (откройте в браузере);
- `niches.csv` и `outlier_videos.csv` — таблицы для Excel;
- `history.json` — память прошлых запусков (не удаляйте, на ней строится колонка «Тренд»).

## 3. Квота
Один полный запуск тратит около 6 000 единиц из 10 000 бесплатных в день, то есть **1 запуск в день**.
Хотите больше: уменьшите `max_search_calls` в блоке CONFIG или создайте второй проект с ключом.

## 4. Автоматический запуск на GitHub
Проект настроен (`.github/workflows/radar.yml`): GitHub каждый день около 8:45 по Варшаве запускает радар
и сохраняет результаты в папку `report/` прямо в репозитории.
- Ключ: **Settings → Secrets and variables → Actions → New repository secret**, имя `YT_API_KEY`.
- Результаты: откройте `report/NICHES.md` — таблица топ-ниш с ссылками; `report/niches.csv` GitHub тоже показывает таблицей.
- Ручной запуск: **Actions → Радар ниш YouTube → Run workflow**.
- История между запусками хранится в `report/history.json` — не удаляйте.

## 5. Как выбирать нишу
Лучший кандидат: много разных каналов (5+), большое соотношение просмотров к подписчикам (×10+),
высокая доля молодых каналов и рост от запуска к запуску. Всегда открывайте примеры видео глазами:
часть тем окажется шумом (одно слово из названия) или разовым хайпом.
